Key Security & Cloud Principles Implemented

  • Zero Key Leakage: Storage credentials and connection strings are strictly retained on the backend; the client never receives storage keys.
  • Private Container Security: Container access level is private; anonymous public read access is explicitly forbidden.
  • Path Traversal Defense: Filenames are sanitized through secure_filename() to mitigate directory traversal attacks.
  • Chunked Stream Transfers: Download routes stream blobs in small chunks using Response(stream_with_context()), preserving server memory.
